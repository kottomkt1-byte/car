# 차분히 · CHABUNHI

연봉뿐 아니라 자산·비상금·생활비·부채·확정된 가족 지원·차량 유지비를 함께 고려하는 한국어 자동차 예산 계산기입니다. 선택한 디자인은 **③ 프리미엄 드림카 쇼룸**입니다. 상단 `디자인 3종`에서 화이트 금융 앱과 크림·라임 테마도 비교할 수 있습니다.

## 실행

Node.js 20 이상이 필요합니다. 설치할 외부 패키지는 없습니다.

```sh
npm start
# http://localhost:4173
npm test
npm run check
npm run build
npm run preview:file
```

- 서비스 파일: `dist/`에 생성됩니다. 상대경로를 사용하므로 저장소 하위 경로에서도 동작합니다.
- 단일 파일 미리보기: `artifacts/chabunhi-preview.html`을 브라우저에서 직접 열면 됩니다. CSS, JavaScript, 자동차 SVG가 모두 포함됩니다.
- HTTP 환경에서 원래 소스를 실행하려면 `npm start`를 사용합니다. 원본 `index.html`을 `file://`로 열면 ES 모듈 보안 제한이 생길 수 있습니다.
- 금융정보는 브라우저 메모리에만 유지됩니다. 새로고침하면 예시 값으로 초기화됩니다.

## 구현한 경험

1. **나의 일상:** 실수령액 직접 입력 또는 연봉 × 직접 설정한 수령 비율, 추가 수입, 생활·주거·대출·육아 지출, 월 저축 목표.
2. **나의 자산:** 예금, 금융자산과 현금화 비율, 보호할 자금, 비상금 개월 수, 차량 투입 비율, 부모님 총자산, 확정 지원금, 순자산, 기존 차량 순매각액.
3. **나의 드림카:** 실제 희망 차량 가격, 일시불 또는 원리금균등 할부, 금리, 취득·등록비, 보유기간, 잔존가치.
4. **타는 매일:** 동력 종류, 연간 주행거리, 연비·전비, 연료·충전 단가, 보험·세금·정비·주차·통행료, 대중교통 비교, 라이프스타일.
5. **결과:** 여유 예산과 빠듯한 상한선, 가족 지원 없는 예산, 소비 유형, 현금흐름, 총소유비용, 소득·금리 충격 가정, 다른 가격 비교, 세부 계산 근거.
6. **공유:** Web Share 또는 클립보드·수동 복사, 1080×1350 PNG 유형 카드, 상세 결과 인쇄. 공유 유형 카드와 링크에는 금액·소득·가족 정보가 없습니다. 인쇄에는 상세 내역이 있습니다.
7. **쇼핑:** 라이프스타일별 용품 체크리스트. 실제 파트너스 링크 설정 시 광고 고지와 외부 링크가 함께 활성화됩니다.

## 계산의 경계

모든 내부 금액 단위는 **만원**입니다. 입력 기본값은 예시이며 최신 가격·보험 견적·세율 데이터가 아닙니다. 정확한 실수령액, 보험 견적, 취득비용과 연비를 입력하는 방식입니다.

- 여유 월 차량 예산은 `min(월 소득 × 설정 비율, 저축 후 가용소득 × 70%)`입니다. 기본 소득 비율은 20%이며 수정 가능합니다.
- 빠듯한 상한은 `min(소득 × (설정 비율 + 10%p, 최대 50%), 가용소득)`입니다. 공식 금융 규칙이나 대출 승인 한도가 아닙니다.
- 가용자산은 예금과 현금화할 금융자산입니다. 비상금과 보호할 목표자금을 차감한 뒤 차량 투입 비율을 적용합니다.
- 부모님 총자산, 부동산과 임차보증금은 구매 자금에 더하지 않습니다. 부모님 자산은 선택적 참고값이며 예산·유형·공유에 영향을 주지 않습니다. 실제 받기로 확정된 순수 지원금만 반영합니다.
- 지원금에 관한 증여 비용이나 세무 판단을 자동 계산하지 않습니다. 비용을 뺀 실제 수령액을 입력합니다.
- 매각할 차의 대출을 제외한 기존 부채 잔액은 순자산에, 상환액은 월 지출에 반영합니다. 둘을 초기자금에서 중복 차감하지 않습니다. 만기 일시상환을 위해 필요한 적립은 월 상환액 또는 보호자금에 반영해야 합니다.
- 비상금이 부족하거나 월 유지비를 감당할 수 없으면 여유 예산은 0원입니다.
- 월 지출은 할부금과 유지비, 보유비용은 감가상각·취득비용·보유기간 발생 이자·유지비입니다. 원금 상환과 감가상각을 중복 계산하지 않습니다.
- 차값·취득비용을 합친 금액에서 초기자금을 뺀 나머지를 할부 원금으로 가정합니다. 실제 상품의 취득비용 금융 포함 여부는 별도 확인이 필요합니다.
- 차량 가격 비교는 동일한 보험·연비·금리·잔존가치 가정을 사용합니다. 특정 차종의 최신 시세 또는 매수 추천이 아닙니다.
- 유형은 앱의 계산 조건으로 정한 재미 요소입니다. 인구 대비 순위·과학적 성향검사·신용평가가 아닙니다.

총비용 구성 참고: [CFPB 자동차 구매 예산](https://www.consumerfinance.gov/ask-cfpb/how-much-can-i-afford-to-borrow-for-a-car-or-auto-loan-en-751/).

## 쿠팡 파트너스 연결

현재 상품 링크는 모두 비어 있으며 **수익 추적이 활성화되어 있지 않습니다.** 실제 상품·가격·후기·할인을 꾸며내지 않습니다.

1. 본인의 [쿠팡 파트너스](https://partners.coupang.com/) 계정에서 실제 서비스 주소를 활동 채널로 등록하고 현재 운영 정책을 확인합니다.
2. 거치대·세차용품·비상용품 등 실제로 연결할 상품의 파트너스 링크를 생성합니다.
3. `src/affiliates.js`의 각 항목 `url`에 해당 링크를 입력하고 `title`, `description`도 실제 상품과 일치시킵니다. 지원하는 주소는 HTTPS의 `link.coupang.com`과 `coupa.ng`입니다.
4. `npm test && npm run check && npm run build` 후 다시 배포합니다.
5. 결과 화면에서 고지와 링크가 함께 보이는지, 각 상품의 목적지가 맞는지 실제 모바일에서 확인합니다.

실제 링크가 하나라도 표시되면 추천 영역 위에 “이 페이지는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.”가 표시됩니다. 링크에는 `rel="sponsored noopener noreferrer"`를 지정합니다. 링크 없는 항목에는 구매 버튼이 없습니다.

결과 확인 전에 광고를 강제하거나 공유해야 결과를 보여주는 장치는 없습니다. 금융 입력값을 광고 URL에 붙이거나 외부로 보내지 않습니다. API 키, 비밀번호 또는 파트너스 계정 인증정보를 소스에 넣지 마세요.

바이럴·수익 개선을 위해 우선 비교할 것은 **검사 완료율, 유형 공유율, 추천 상품 클릭률**입니다. 이 버전에는 분석 SDK와 집계 서버가 없어 측정은 아직 연결하지 않았습니다. 연결 시 원시 금융정보 없이 별도 이벤트만 처리해야 합니다. 매출은 실제 유입과 구매에 따라 달라집니다.

## 배포

### GitHub Pages

소스를 `kottomkt1-byte/car`에 업로드한 뒤 저장소 **Settings → Pages → Source: GitHub Actions**를 선택합니다. **Actions → Deploy GitHub Pages → Run workflow**를 실행합니다. 워크플로가 반환한 실제 주소가 배포 주소입니다. 업로드만으로 자동 배포되지 않도록 배포 워크플로는 수동 실행입니다.

체크 워크플로는 push/PR 시 문법 검사·테스트·빌드를 실행합니다. 비어 있는 저장소의 최초 업로드에는 아직 PR 대상 브랜치가 없으므로 먼저 초기 커밋이 필요합니다.

### 다른 정적 호스팅

빌드 명령은 `npm run build`, 게시 디렉터리는 `dist`입니다. Node 의존성이나 서버 DB가 필요하지 않습니다. 외부 분석·광고·웹폰트 요청도 없습니다.

실제 주소를 정한 후 canonical, `og:url`, 절대주소 `og:image`와 사이트맵을 추가하면 검색·SNS에 도움이 됩니다. 현재는 미확정 주소를 메타데이터에 넣지 않았습니다.

## 파일 구조

```text
index.html              페이지 구조와 메타데이터
src/styles.css          반응형 쇼룸 디자인과 대안 테마
src/app.js              4단계 입력, 결과·비교·시나리오, 접근성 처리
src/calculator.js       UI에서 분리한 재무 계산
src/share.js            개인정보 없는 공유 문구·PNG 카드
src/affiliates.js       상품 구성과 파트너스 URL 검증
public/car.svg          오리지널 자동차 벡터 일러스트
tests/calculator.test.mjs 계산·개인정보·외부 링크 테스트 25개
scripts/                개발 서버·빌드·단일 HTML 출력
.github/workflows/      자동 검사와 수동 Pages 배포
```

키보드 포커스, 입력 라벨, 오류 안내, 모달, 줄어든 모션 설정과 인쇄 레이아웃을 포함합니다. CSS는 모바일부터 데스크톱까지 대응합니다.

검증한 내용:

- 계산·공유정보 보호·제휴 링크 테스트 25개 통과.
- JavaScript 문법, 정적 빌드, 단일 HTML 안의 통합 스크립트 문법, 파일 경로와 중복 ID 검사 통과.
- 개발 서버에서 HTML·JS·CSS·SVG 응답과 Git 내부 파일 차단 확인.
- 임시 jsdom 환경에서 입력 유효성, 4단계 이동, 실시간 예산, 확정 지원, 전기차 기본값 전환, 결과 생성, 가격 비교, 시나리오, 공유 정보, 테마 전환, 결과 갱신, 초기화, 예시 불러오기 확인.
- 실제 브라우저 자동화 연결이 없어 렌더링·터치·다운로드·인쇄의 실제 브라우저 QA는 미완료입니다. DOM 모사 테스트는 시각적 검증을 대신하지 않습니다.

디자인 방향 참고: [토스](https://toss.im), [16Personalities](https://www.16personalities.com/ko), [포르쉐](https://www.porsche.com/korea/ko/). 화면과 자동차 SVG는 이 프로젝트용으로 작성했으며 해당 브랜드와 제휴하지 않습니다.
