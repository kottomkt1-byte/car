# 차분히 · 내 연봉으로 무슨 차 탈 수 있을까?

연봉, 월 지출, 내 자산, 부모님 자산 네 가지만 입력하면 서로 다른 차 3대를 비교합니다. 경차부터 롤스로이스까지 63개 모델, 신차·중고를 나눈 68개 가격 옵션을 포함합니다. 프리미엄 다크 쇼룸 디자인에 오렌지 강조색과 밝은 입력창을 사용합니다.

## 실행

Node.js 20 이상. 설치할 런타임 패키지는 없습니다.

```sh
npm start
npm test
npm run check
npm run build
npm run preview:file
```

- 개발 주소: http://localhost:4173
- 정적 배포 디렉터리: `dist/`
- 단일 HTML: `artifacts/chabunhi-preview.html`. CSS와 JavaScript, 메인 차량 이미지와 광고 배너 이미지를 내장합니다. 추가 차량 사진과 웹폰트에는 인터넷이 필요합니다.
- 원본 index.html은 HTTP로 여세요. file:// 미리보기에는 위 단일 HTML을 사용합니다.

## 사용 흐름

1. 같은 화면에서 금액 네 개를 입력합니다. 단위는 만원입니다.
2. 동일한 크기의 카드 3개에서 차 이름·차값·월 할부+유지비를 비교합니다.
3. 카드의 비용 내역을 열면 초기 납입금, 월 할부와 유지비, 별도 유지비 자금을 봅니다.
4. 예산에 맞는 모델이 3개보다 적으면 나머지를 예산 초과 후보로 명시하고 부족 자금을 표시합니다. 구매 가능하다고 가장하지 않습니다.
5. 부모님 지원을 받는 경우는 결과의 별도 버튼으로 비교합니다.
6. 예산에 맞는 추천 3대와 지원 가정 여부를 공유하거나 PNG 카드로 저장합니다. 금융 입력값과 예산 초과 후보는 공유에서 빠집니다. 전체 차종 버튼으로 63개 모델과 가격 가정을 볼 수 있습니다.

## 추천 기준과 한계

`src/calculator.js`의 비율은 서비스의 비교용 가정입니다. 검증된 재무설계 공식·대출 승인 기준이 아니며, 실제 월급과 유지비를 입력받는 정밀 견적도 아닙니다.

- 추정 월 수입: 세전 연봉 × 80% ÷ 12. 실제 세금·공제를 계산하지 않습니다.
- 자산 입력: 부채를 뺀 예금·매도 가능한 투자금. 부동산·연금·보증금은 제외합니다.
- 비상금 목표: 월 지출 × 6. 부족하면 차종 전체를 탈락시키지 않고, 부족액을 24개월에 나눠 모으는 금액만큼 월 여유를 줄입니다.
- 월 차량 예산: `max(0, 추정 월 수입 - 지출 - 비상금 적립액) × 35%`. 이전의 소득 25% 상한에 고정되는 구간을 없앴습니다. 지출이 바뀌면 예산도 연속적으로 바뀝니다.
- 생활비가 소득을 넘으면 부족액의 60개월치를 자산에서 먼저 확보합니다. 그 돈과 6개월 비상금을 남긴 뒤 내 남은 자산의 35%를 차 구입·유지에 배정합니다.
- 부모님 자산은 기본 결과에 합산하지 않습니다. **지원 가정**에서는 부모님 자산의 2%, 최대 1억원을 가상의 순수 지원금으로 더합니다. 이 비율은 임의의 비교 가정이며 실제 지원 약속이나 증여세 계산이 아닙니다. 지원금은 부족한 비상금·생활비에 먼저 배정하고 나머지를 차량 자금에 더합니다.
- 차량 총 구입비는 차량가 × 1.07 + 30만원입니다. 차종별 유지비는 보험·연료/충전·세금·주차·정비의 고정 월평균 가정입니다.
- 월 차량 예산으로 유지비가 부족하면 부족분의 60개월치를 차량 자금에서 먼저 남깁니다. 남은 자금은 초기 구입비, 부족한 구입비는 60개월·연 6% 원리금균등 할부로 계산합니다. 자산만으로 구매하는 사람도 차값과 유지비를 중복 사용하지 않습니다.
- 조건에 맞는 상위 가격대에서 서로 다른 모델 3대를 고릅니다. 첫 후보는 가장 높은 차량가, 다음 후보는 비슷한 가격대의 다른 브랜드·차체 유형을 우선합니다. 차체 종류만 맞추느라 가격대가 크게 내려가지 않도록 한 번 더 범위를 제한합니다. 같은 모델의 신차·중고차는 한 자리만 차지합니다. 가격대 사이에서는 같은 모델이 나올 수 있으며 가족 구성·취향을 맞추는 추천은 아닙니다.
- 같은 결과여도 월 예산과 차량 자금은 함께 표시합니다. 금액을 수정해 다시 계산하면 이전 입력과 예산을 비교하며, 선택한 지원 모드를 유지합니다.
- 맞는 모델이 0~2대면 부족 자금이 적은 다른 모델로 비교 슬롯을 채우고 예산 초과로 표시합니다. 이들은 추천 가능 차량 수와 공유에서 제외합니다. 동일하게 세 카드가 보이지만 세 대 모두 구매 가능하다는 뜻은 아닙니다.

차량 가격은 최신 실매물 가격이 아닌 **비교용 가정**입니다. K3는 중고차로만 분류합니다. 실제 세후 소득·대출 심사·견적·보험료·주행거리·보유기간·물가에 따라 판단이 달라집니다. 실제 상품의 취득비용 금융 포함 여부도 별도 확인이 필요합니다.

## 수정한 오류의 재현

이전 버전에서는 연봉 1억원, 내 자산 1,800만원, 부모님 자산 40억원에서 지원 가정을 켠 경우, 월 지출 300만원은 마칸, 301만원은 추천 없음이었습니다. `reserveGap === 0`이 모든 차량에 적용되는 통과 조건이어서 비상금 6만원 차이로 전체 결과가 바뀌었습니다. 이 조건을 제거하고 비상금 적립·자금 배정을 연속적으로 계산합니다.

또 지원 모드에서 금액을 수정하면 기본 모드로 초기화되던 폼 제출 동작을 수정했습니다. 모드는 명시적으로 바꿀 때와 예시를 선택할 때만 바뀝니다.

비상금 경계의 월 지출 300만원 → 301만원 사례는 모드가 유지되고 월 차량 예산이 연속적으로 변합니다. 모델 목록 확대에 따라 개별 추천은 달라질 수 있지만, 이 경계에서 추천 전체가 사라지는 문제는 회귀 테스트로 확인합니다.

## 넓어진 차종 목록과 고소득 구간

63개 모델 / 68개 가격 옵션: 경차·국산 세단·SUV·하이브리드·전기차·수입차·스포츠카·럭셔리 세단 등을 포함합니다. 같은 모델의 신차·중고는 모델 수에 중복 집계하지 않습니다. 목록은 `src/calculator.js`의 `ORIGINAL_CARS`, `MORE_CARS`에서 관리합니다.

## 이미지와 디자인

- `public/showroom.png`: 이 프로젝트를 위해 생성한 AI 실버 스포츠카 참고 이미지. 외관·사양 보증용이 아닙니다.
- `src/car-media.js`: 전체 63개 차종 / 68개 가격 옵션의 실제 차종별 대표 이미지와 출처를 한곳에서 관리합니다. 신차·중고가 같은 사진을 쓸 수 있으며 연식·옵션 차이를 카드에 표시합니다. 추천 카드의 911도 실제 모델 이미지로 연결했습니다.
- 원본 제공처의 외부 이미지를 불러옵니다. 2026-10-17 웹 도구에서 전체 주 이미지가 이미지 응답을 반환하는 것을 확인했습니다. 별도 재배포 라이선스를 주장하거나 사진을 무단으로 로컬 재호스팅하지 않습니다.
- 결과 사진 3장은 즉시 요청합니다. 오류 이벤트를 등록한 뒤 요청을 시작하고, 확인된 대체 이미지가 있으면 전환하며 각 주소는 한 번만 자동 재시도합니다. 12초 이상 응답이 없어도 다음 시도로 넘어갑니다. 모두 실패하면 재시도 버튼을 표시하며 다른 차의 사진을 대신 쓰지 않습니다.
- `object-fit: contain`으로 차량 전체가 보이게 표시합니다. 이미지를 가져오는 중과 연결 오류를 구분하고, 입력 변경 시 이전 이미지의 타이머·이벤트를 정리합니다.
- 외부 이미지 서비스의 가용성과 방문자 네트워크에 따라 표시가 달라질 수 있습니다. 자동 검사와 DOM 시뮬레이션으로 누락·실패·재시도는 확인했으며, 이 환경에는 연결된 브라우저 도구가 없어 실제 브라우저 화면 검증은 수행하지 못했습니다.
- 외부 Noto Sans KR 웹폰트가 실패해도 시스템 글꼴로 동작합니다. 모든 핵심 레이아웃 CSS는 로컬 파일입니다.
- 제조사와 제휴한 서비스가 아닙니다.

## 개인정보와 공유

금액은 브라우저 메모리에서만 계산합니다. 저장소·쿠키·서버·광고 URL에 넣지 않습니다. 새로고침하면 예시값으로 초기화됩니다. 외부 폰트·사진 요청과 외부 링크 이동은 발생할 수 있으며 호스팅의 일반 접속 기록은 별도입니다.

공유 링크의 검색 매개변수와 해시는 제거합니다. 공유 문구·PNG에는 예산에 맞는 최대 3대의 차 이름, 트림, 지원 가정 여부만 남깁니다. Web Share를 사용할 수 없으면 클립보드, 그마저 실패하면 수동 복사 창을 제공합니다.

## 쿠팡 파트너스

결과 화면에 미스터리 박스 이미지와 “비싼 차 없어도, 여자에게 사랑받는 남자가 되려면… 이게 필요합니다.” 문구, “클릭하기” 버튼을 표시합니다. PC에서는 추천 3대 아래, 모바일에서는 첫 번째 추천차 바로 아래에 배치합니다. 화면 크기가 바뀌면 실제 DOM 순서도 함께 바뀝니다.

`src/affiliates.js`의 `MYSTERY_TEASER`에 운영자가 제공한 `https://link.coupang.com/a/hYcAlLnFNk`를 연결했습니다. `public/mystery-box.png`는 생성한 추상적인 티저 이미지로 실제 상품 사진이 아닙니다. 배너 전체를 누르면 새 창으로 쿠팡 링크를 엽니다. 별도 AD 배지 없이 배너 문구 위에 다음 고지를 12px로 표시합니다.

> 이 링크는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

링크에는 `rel="sponsored noopener noreferrer"`를 붙입니다. 금액을 광고 URL에 붙이지 않으며 결과 확인 전 광고나 공유를 강제하지 않습니다. 별도 클릭 추적 코드는 없습니다. HTTPS의 `link.coupang.com`, `coupa.ng` 주소만 허용합니다. 기존 `PRODUCTS`는 추후 상품별 카드를 추가하기 위한 설정이며, 실제 링크가 비어 있는 항목은 숨깁니다. 실제 사이트 주소를 파트너스 활동 채널로 등록하고 현재 운영 정책을 확인하세요.

## 검증과 배포

`npm test`는 계산 경계, 지원금 분리, 현금·대출·유지비 회계 일치, 무소득 자산 보유자, 입력 변화의 방향성, 공유정보 보호, 제휴 링크 등을 검사합니다. 월 지출을 1만원씩 바꾸는 42,060개 조합에서 각 모델의 자금 여유가 연속적으로 변하고, 고가 차에서 추천 없음으로 갑자기 떨어지지 않는지 확인합니다. 차종마다 유지비가 달라 카탈로그 순번 차이를 재무적 급변으로 취급하지 않습니다. 비상금·월 여유·지원금 배정의 경계 양쪽에서도 금액이 연속적인지 검사합니다. 금융적 적정성이나 최신 시장가격 검증을 대신하는 테스트는 아닙니다.

3억·30억 연봉 비교, 정확히 세 개의 서로 다른 모델, 신차·중고 중복 방지, 0~2대만 예산에 맞는 경우의 구분도 검사합니다. 임시 jsdom으로 세 카드, 63개 모델 목록, 지원 모드 유지, 이전 결과 비교, 입력 오류, 세 대 공유·PNG와 사진 실패 처리를 확인합니다. 실제 브라우저 자동화가 연결되지 않아 렌더링과 기기별 다운로드는 별도 검증이 필요합니다.

GitHub Pages를 사용하려면 소스를 업로드하고 Settings → Pages → GitHub Actions에서 수동 Deploy GitHub Pages 워크플로를 실행합니다. 체크 워크플로는 push/PR에서 동작합니다. Sites 배포는 기존 프로젝트 식별자와 공개 범위를 유지하며 `.openai/hosting.json`은 해당 호스팅 프로젝트 전용입니다.
