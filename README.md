# 차분히 · 내 연봉으로 무슨 차 탈 수 있을까?

연봉, 월 지출, 내 자산, 부모님 자산 네 가지만 입력하면 실제 차종을 추천합니다. 프리미엄 다크 쇼룸 디자인에 오렌지 강조색과 밝은 입력창을 사용합니다.

## 실행

Node.js 20 이상. 설치할 런타임 패키지는 없습니다.

```sh
npm start
npm test
npm run check
npm run build
npm run preview:file
```

- 개발 주소: http://localhost:4173
- 정적 배포 디렉터리: `dist/`
- 단일 HTML: `artifacts/chabunhi-preview.html`. CSS와 JavaScript, 메인 차량 이미지를 내장합니다. 추가 차량 사진과 웹폰트에는 인터넷이 필요합니다.
- 원본 index.html은 HTTP로 여세요. file:// 미리보기에는 위 단일 HTML을 사용합니다.

## 사용 흐름

1. 같은 화면에서 금액 네 개를 입력합니다. 단위는 만원입니다.
2. 아반떼·K3, G80·BMW 5시리즈, 포르쉐 등 구체적인 차 이름이 나옵니다.
3. 월 할부+유지비, 초기 납입금, 비상금, 생활비·차 비용을 낸 뒤 남는 돈을 봅니다.
4. 더 저렴한 추천 차를 최대 두 대 보여줍니다. 조건을 충족하는 차량이 없으면 구매 보류로 안내합니다.
5. 부모님 지원을 받는 경우는 결과의 별도 버튼으로 비교합니다.
6. 추천 차 이름과 지원 가정 여부를 공유하거나 PNG 카드로 저장할 수 있습니다. 금융 입력값은 포함하지 않습니다.

## 추천 기준

`src/calculator.js`의 가정값은 금융기관의 승인 기준이 아닌 간편 비교 규칙입니다.

- 추정 월 수입: 세전 연봉 × 80% ÷ 12. 실제 세금·공제를 계산하지 않습니다.
- 내 자산: 부채를 뺀 예금·매도 가능한 투자금. 부동산·연금·보증금은 제외합니다.
- 초기자금: 자산에서 월 지출의 6배를 비상금으로 남긴 뒤 나머지의 35%.
- 월 차량 예산: 월 수입의 25%와 월 지출 후 남은 돈의 50% 중 작은 금액.
- 구매 총액: 차량가 + 차량가의 7% + 30만원. 초기자금으로 부족한 금액은 연 6%, 60개월 원리금균등상환으로 가정합니다. 실제 금융상품의 취득비 금융 포함 여부는 별도 확인해야 합니다.
- 월 부담: 할부금 + 차종별 유지비. 유지비는 보험·연료/충전·세금·주차·정비의 월평균 가정으로, 운전자·주행거리·거주지별 실제 견적은 다릅니다.
- 기본 추천은 부모님 자산을 구매자금으로 합산하지 않습니다. **부모님 지원 가정** 버튼에서만 부모님 자산의 2%, 최대 1억원을 순수 지원금으로 가정합니다. 실제 지원 약속이나 증여세 계산을 의미하지 않습니다.
- 비상금이 부족하거나 월 여유가 없으면 구매를 보류합니다. 지원금을 비상금 부족분으로 사용하지 않습니다.
- 조건을 만족하는 카탈로그 차량 중 가격이 가장 높은 차와 더 저렴한 대안을 보여줍니다. 용도·좌석·주행 성향까지 맞추는 추천은 아닙니다.

차량 가격은 최신 실매물 가격이 아닌 **비교용 가정**입니다. K3는 중고차로만 분류합니다. 제조사 공식 링크에서 실제 옵션·판매가를 확인할 수 있습니다. 카탈로그와 유지비는 `CARS`에서 수정합니다.

## 이미지와 디자인

- `public/showroom.png`: 이 프로젝트를 위해 생성한 AI 실버 스포츠카 참고 이미지. 외관·사양 보증용이 아닙니다.
- BMW·제네시스·아반떼·K3: 카탈로그 `source`에 출처 URL을 기록하고 결과 화면에서 연결합니다. 대표 사진은 추천 연식·트림과 다를 수 있습니다. 이미지는 원본 제공처에서 불러옵니다.
- 사진이 없거나 로딩에 실패하면 브랜드와 모델명을 표시합니다. 다른 차의 사진을 대신 붙이지 않습니다.
- 외부 Noto Sans KR 웹폰트가 실패해도 시스템 글꼴로 동작합니다. 모든 핵심 레이아웃 CSS는 로컬 파일입니다.
- 제조사와 제휴한 서비스가 아닙니다.

## 개인정보와 공유

금액은 브라우저 메모리에서만 계산합니다. 저장소·쿠키·서버·광고 URL에 넣지 않습니다. 새로고침하면 예시값으로 초기화됩니다. 외부 폰트·사진 요청과 외부 링크 이동은 발생할 수 있으며 호스팅의 일반 접속 기록은 별도입니다.

공유 링크의 검색 매개변수와 해시는 제거합니다. 공유 문구·PNG에는 차 이름, 트림, 지원 가정 여부만 남깁니다. Web Share를 사용할 수 없으면 클립보드, 그마저 실패하면 수동 복사 창을 제공합니다.

## 쿠팡 파트너스

현재 실제 파트너스 링크가 없어서 추천 상품 영역은 숨겨져 있습니다. 수익 추적도 활성화되지 않았습니다.

`src/affiliates.js`에 본인 계정의 실제 상품 링크를 넣고 제목과 설명을 해당 상품에 맞추세요. HTTPS의 `link.coupang.com`, `coupa.ng` 주소만 허용합니다. 유효한 링크가 있으면 결과 하단에 상품과 다음 고지가 함께 나타납니다.

> 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

링크에는 `rel="sponsored noopener noreferrer"`를 붙입니다. 금액을 광고 URL에 붙이지 않으며 결과 확인 전 광고나 공유를 강제하지 않습니다. 실제 사이트 주소를 파트너스 활동 채널로 등록하고 현재 운영 정책을 확인하세요.

## 검증과 배포

계산·추천 경계·부모님 지원 분리·공유정보 보호·제휴 링크에 대한 Node 테스트가 있습니다. JavaScript 문법 검사와 정적 빌드도 실행합니다. 임시 jsdom 검사로 네 가지 입력, 예시 선택, 지원 모드, 결과 재입력, 오류 처리, 공유, 사진 실패 처리를 확인합니다. 실제 브라우저 자동화는 연결되지 않아 픽셀 단위 렌더링과 기기별 다운로드는 검증하지 못했습니다.

GitHub Pages를 사용하려면 소스를 저장소에 업로드하고 Settings → Pages → GitHub Actions를 선택한 뒤 수동 Deploy GitHub Pages 워크플로를 실행합니다. 체크 워크플로는 push/PR에서 동작합니다. 현재 Sites 배포는 기존 프로젝트 식별자와 공개 범위를 유지합니다. Sites 소스의 `.openai/hosting.json`은 해당 호스팅 프로젝트 전용입니다.
